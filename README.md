# 🍓 Frutberry

Simple daily ledger for juice supply businesses. Runs in any browser, no server needed.

## Features
- Shops: name and mobile number
- Daily sales entries: item, quantity, rate, amount received
- Payment-only entries for old dues
- Daily purchase list with supplier
- Per-shop credit/debit balance and full ledger
- Daily summary: sales, received, purchases, total to collect

## Run
Open `index.html` in a browser.

## Host free on GitHub Pages
1. Create a repository named `frutberry`
2. Upload `index.html` and `README.md`
3. Go to Settings → Pages → Branch: `main` / root → Save
4. Your app will be live at `https://<your-username>.github.io/frutberry/`

## Note
Data is stored in the browser (localStorage) on each device. Cloud sync and export are planned.
